# SQLParser

Converts SQL text into an abstract syntax tree (AST).

`SQLParserProcessor.Parse(sql)` is the single public entry point. It instantiates the LALR(1) parser generated by GPPG/GPLEX and passes the resulting `NodeAst` through `IdentifierNormalizer` which lower-cases unquoted identifiers.

The grammar and lexer live in `SQLParser.Language.grammar.y` and `SQLParser.Language.analyzer.lex`; GPPG/GPLEX compile them into `SQLParser.Parser.Generated.cs` and `SQLParser.Scanner.Generated.cs` (regenerated on build — do not edit). `sql.Parser.cs` and `sql.Scanner.cs` are hand-written partial-class companions of the generated `sqlParser` / `sqlScanner` (the `Parse(string)` entry point, the `yyerror` override); they are scaffolded once and are **not** overwritten when the grammar/lexer change, so they are the place for hand-authored parser/scanner code.

Key types:

| Type | Purpose |
|------|---------|
| `NodeAst` | Tree node — holds a `NodeType`, optional string value, and up to two child nodes |
| `NodeType` | Enum of every grammar production (statement types, operators, literals, …) |
| `NodeTypeExtensions` | Helpers for classifying and printing node types |
