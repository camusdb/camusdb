# SQLParser

Converts SQL text into an abstract syntax tree (AST).

`SQLParserProcessor.Parse(sql)` is the single public entry point. It instantiates the LALR(1) parser generated by GPPG/GPLEX from the grammar defined in `sql.Parser.cs` / `sql.Scanner.cs` (the generated files are `SQLParser.Parser.Generated.cs` and `SQLParser.Scanner.Generated.cs`), then passes the resulting `NodeAst` through `IdentifierNormalizer` which lower-cases unquoted identifiers.

Key types:

| Type | Purpose |
|------|---------|
| `NodeAst` | Tree node — holds a `NodeType`, optional string value, and up to two child nodes |
| `NodeType` | Enum of every grammar production (statement types, operators, literals, …) |
| `NodeTypeExtensions` | Helpers for classifying and printing node types |
